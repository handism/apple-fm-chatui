# Local FM Chat

Macの **Apple Foundation Models** と、VS Codeのサイドバーで会話する拡張機能です。Apple公式フレームワークを使用した個人開発の拡張であり、Apple公式の拡張機能ではありません。

## 必要な環境

- Apple Silicon搭載Mac、macOS 26以降
- Apple Intelligenceが有効で、オンデバイスモデルのダウンロードが完了していること（対応言語・地域を含め、実際の利用可否は起動時に確認）
- VS Code 1.95以降のデスクトップ版

## インストールと使い方

1. [GitHub Releasesの最新版](https://github.com/handism/apple-fm-chatui/releases/latest) から `apple-fm-chatui-darwin-arm64-<バージョン>.vsix` をダウンロードします。cloneやNode.jsのインストールは不要です。
2. VS Codeの拡張機能画面で「…」→「VSIXからのインストール」を選び、ダウンロードしたVSIXを指定します。
3. アクティビティバーの吹き出しアイコンを開きます。コマンドパレットの `Local FM: チャットを開く` でも開けます。
4. 「利用可能 · 応答はまだ未確認」と表示されたら入力して送信します。回答の受信が完了すると「応答確認済み」に変わります。Enterで送信、Shift+Enterで改行。日本語変換中のEnterでは送信しません。

回答は順次表示され、コピーできます。「停止」で生成を中断し、「新しい会話」で会話を消去できます。エディタの選択部分は右クリックの `Local FM: 選択テキストをチャットに添付` で添付し、質問と一緒に送信できます。ファイルを自動で読み取る機能はありません。

## 選択テキストの定型アクションと差分適用

1. エディタで文章を1か所選択します。
2. 右クリックまたはコマンドパレットから、`Local FM: 選択テキストを要約` / `読みやすくする` / `英訳` / `箇条書きにする`を実行します。
3. サイドバーに結果が出たら「差分を見る」を押します。別のエディタグループで、文章全体の変更前・変更後を読み取り専用で比較できます。
4. 内容を確認したら、サイドバーの結果にある「選択範囲に適用」を押します。候補を使わない場合は「破棄」。

適用は実行時に選んだ範囲だけを置き換えます。自動保存はしません。元に戻すには元のエディタでUndo（⌘Z）を使います。途中で別のファイルや選択範囲へ移動しても、適用先は実行時の文章です。

生成開始後に元の文書のどこかが変更された場合、元の文書を閉じた場合、生成を停止した場合は適用できません。変更をUndoで戻しても候補は再利用できないため、選択し直して実行してください。「新しい会話」は編集候補も破棄します。差分を開く前の適用や、同じ候補の二重適用はできません。

選択テキストは8,000文字以内・1か所のみです。モデルの会話長の上限とは異なるため、長い文章で上限エラーが出た場合は選択を短くしてください。編集候補は1会話につき20件までです。

定型アクションは通常のチャット履歴や添付を使わず、選択した文章だけを独立して処理します。チャットの入力途中の下書きと添付はそのまま残します。元の文書が変わっていないかは文書全体のハッシュで確認し、差分表示用の文書全体は差分を開いている間だけメモリ内に保持します。モデルには選択範囲以外の文章を渡しません。

## モデルの状態・診断

「モデルの状態・診断」を開くと、最後の利用可否確認と、この拡張ホストの起動中に最後に回答を受信し終えた日時を確認できます。利用可否のチェックでは文章生成を実行しません。過去の応答成功は、その後のリクエストの成功を保証するものではありません。

エラー時は診断欄を開き、モデル準備中、Apple Intelligence無効、会話長の上限、回答拒否、対応言語、混雑、起動失敗、タイムアウトなどに合わせた次の操作を案内します。「再確認」は履歴を消さずに利用可否だけを確認し、会話の上限に達した場合は古いやり取りから自動で省いて再生成し、その旨を回答の下に表示します。

「診断情報をコピー」は、拡張・VS Codeのバージョン、OSのDarwinバージョン、CPUアーキテクチャ、確認日時、最後のエラー分類とApple側のエラードメイン・番号をクリップボードにコピーします。会話本文、回答、添付、ファイルパス、OSの詳細なエラー文章は含めません。コピーした内容の自動送信や保存はありません。

## データの扱いと制約

- 推論には `SystemLanguageModel.default` のオンデバイスモデルを使います。APIキーやHTTPサーバーは不要です。この拡張は外部API、テレメトリ、会話のログ出力を実装していません。
- 会話履歴は拡張ホストのメモリ内のみです。VS Codeの再起動・ウィンドウ再読み込みで消えます。入力途中の下書きはWebviewの状態としてVS Codeが保持します。
- Swiftヘルパーをリクエストごとに起動し、完了した過去のやり取りを型付きTranscriptとして渡します。応答を速くするため、次のリクエスト用のヘルパーを1つ先に起動してモデルを準備させておきます（入力を受け取るまでは何も生成しません）。停止・失敗したやり取りは次回のモデル入力に含めません。
- モデルの会話長には上限があります。上限エラー時は古い方から半分ずつやり取りを省いて自動で再試行し、履歴がなくなっても収まらない場合はエラーを表示します。省いたやり取りは画面に残りますが、以降のモデル入力には含めません。履歴は最新の50往復までを送ります。入力と添付は合計12,000 UTF-16コード単位、添付のみは8,000以内ですが、これはトークン上限を保証するものではありません。回答は最大1,024トークンを指定しています。
- Appleは文章の要約・編集・分類などを主な用途として挙げています。コード生成、数学、複雑な推論の精度には限界があります。
- 表示はプレーンテキストとコードフェンスに対応します。モデル出力をHTMLとして実行せず、リンクやコマンドを自動実行しません。
- Remote SSH等でもUI拡張として手元のMacで動作する設計です。リモート環境との組み合わせは未検証です。ブラウザー版VS Codeには対応しません。

## 開発

Node.js 22以降とmacOS 26以降のSDKを含むCommand Line ToolsまたはXcodeが必要です。配布VSIXにはSwiftバイナリを同梱するため、利用者側のコンパイルは不要です。

```sh
npm install
npm run build:native
npm test
npm run package
```

VS Codeでこのフォルダーを開きF5を押すと、拡張機能開発ホストを起動します。ビルド時はインストール済みのCommand Line Toolsを優先します。別のツールチェーンを使う場合は`DEVELOPER_DIR`を指定してください。システムの設定は変更しません。

```sh
./bin/local-fm --status
printf '%s' '{"prompt":"こんにちは。短く自己紹介してください。","history":[]}' | ./bin/local-fm
```

モデルが準備中の場合はシステム設定のApple Intelligenceの状態を確認し、「再確認」を押してください。生成タイムアウトは180秒、状態確認は15秒です。配布物はローカル用のad-hoc署名で、公証・Marketplace公開はしていません。

### リリース手順

1. `package.json` の `version` を上げてコミットし、mainへpushします（タグ作成は不要）。
2. CI（macOS 26 / Apple Silicon）のテストとビルドが通ると、`v<version>` のGitHub Releaseが未作成の場合に限り、タグ付きでReleaseを作成して `apple-fm-chatui-darwin-arm64-<version>.vsix` を添付します。リリースノートは自動生成です。
